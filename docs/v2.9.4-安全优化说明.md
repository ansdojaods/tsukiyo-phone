# 小手机 v2.9.4：同步与恢复安全优化

基于本地 v2.9.3 修复版继续开发。没有推送 GitHub；不需要新供应商接口。

## 1. 工坊同步变更预览

入口：**世界书工坊 → 同步变更预览**，或原“立即同步”（现为“预览并同步”）。

- 展示新增、修改、取回、删除与双方冲突的数量。
- 展开条目可对照当前手机、当前世界书及本次动作。
- 每页20条，跨页保留选择；确认后只执行选中的可执行变更。
- 冲突项和不支持回灌项不会混入普通同步执行。
- 预览后手机、世界书、聊天/分支发生相关变化，会拒绝旧操作，要求重新预览。
- 未选项只是**本次不执行**，不是永久排除。后续自动同步仍可能执行。需要逐项审批时，请先关闭工坊自动同步。

范围：本版变更差异预览覆盖**世界书工坊**；普通记忆世界书沿用既有同步流程，新增的是导入范围管理与恢复副本保护。新建/连接后的首次同步以及自动同步不会逐次弹出审批框。

## 2. 工坊冲突处理

入口：**世界书工坊 → 处理同步冲突**。

每次选择一条冲突，可使用手机版本、使用世界书版本、手动合并或取消跳过。真正写入之前，先将双方内容备份到本聊天回收站；备份容量不足会停止操作。

- 人物资料采用世界书或合并内容时，保存为人物的“世界书同步”参考资料，**不替换原始人物简介**。
- 灵魂五节档案、生活清单仍不支持将任意远端正文结构化回灌，因此只提供手机版本或跳过，不假装支持回灌。
- 工坊记录处理后的本地基准，避免下一轮同步又覆盖刚确认的结果。
- 冲突备份支持查看和导出；不直接一键回滚，以免覆盖处理之后的新修改。

**手机和世界书仍不是跨系统原子事务。**若远端写入成功后本地提交被拒绝，远端写入可能已发生。异常时核对双方，再利用备份重新处理；不能把错误提示理解成“双方都已回滚”。

## 3. 本聊天回收站

入口：**设置 → 回收站**；灵魂页、记忆页也有入口。

### 保存什么

手机存档事务中被删除的：
- 整份角色灵魂档案的正文结构；
- 手机记忆记录；
- 手动工坊冲突处理前的双方内容备份。

日记、照片、通讯录、单个灵魂分节条目及推演历史不属于这一版的回收范围。它不是全模块历史版本系统。升级前已经删除的内容无法凭空找回。

### 容量与清理

- 最多 **60条**，序列化 JSON 总计不超过 **50万字符**。
- 满时阻止新增删除或冲突备份，**不会静默淘汰旧记录**。
- 可预览、导出所选、永久删除所选；导出文件包含原文，应妥善保管。
- **设置 → 导入回收站备份** 可将导出文件重新合入回收站，重复内容会跳过；导入本身不恢复、不写世界书。

### 恢复边界

- **记忆**：恢复成新ID的本地副本，移除旧世界书绑定，并取消同一本书中原记忆尚未执行的删除队列。副本不参与世界书写出，直到点击 **允许写入世界书**。
- **灵魂档案**：恢复同名档案时不覆盖现有角色；恢复后加入工坊排除清单，也不自动删除现存远端副本。需要写出时，在工坊明确恢复排除，再预览同步。
- 不恢复推演历史，也不自动重新注入旧推演。
- 旧远端记录若还存在，可能与本地恢复副本并列；发布恢复副本前请核对，避免重复记录。

## 4. 不重连即可管理记忆导入范围

入口：**记忆页 → 已连接的记忆世界书 → 管理导入范围**。

- 读取现有普通记忆条目、预览全文、追加或取消勾选。
- 保存范围不立即强制执行同步；下一次手动或自动同步按新范围读取。
- 取消勾选只影响**新条目导入**，不删除手机记忆，也不解除已有绑定。
- 工坊条目仍由工坊管理，不作为普通记忆重复导入。
- 整张角色卡共用时，更新该卡后续自动连接所用的选择范围。

## 5. 升级与兼容性自检

入口：**设置 → 升级与兼容性自检**。

报告包含手机版本、存档校验状态、关键接口是否可见、已连接书是否存在、自动同步状态、联系人数量/可识别的预置缺失数量、剧情时间来源、回收站数量及活动实例信息。

- 导出不含密钥、API地址、聊天原文、人物正文或世界书名称/正文。
- 不同版本共用同一活动实例时会提示停用旧脚本并刷新。
- 只能检查当前页面可见的入口，**不能穷举未运行的脚本或证明不存在所有重复安装**。
- 多个楼层的卡内脚本正常复用实例，不直接判定为多份手机运行。

## 顺手修复的旧问题

- 旧通用记忆批删把待删除项记录成字符串，而同步计划需要 `{id, uid}`；已统一格式，并兼容规范化旧字符串队列。
- 删除队列满时不再静默漏记后续远端删除。
- 记忆页旧“多选删除/一键清空”统一进入带变更校验的预览流程；清空仅预选条目，仍需确认。
- 清空手机记忆不再顺带清空滚动摘要。
- 回收站容量在记忆同步的删除计划执行前预检，避免明知无法备份仍继续写出。

## 测试与安装

本轮通过：115项既有冒烟、16项归属专项、29个既有回归场景、26个新增安全场景；6组既有及8组新增 DOM/真实仓库存储流程。测试宿主与模型接口均为模拟，不是用户真实酒馆/API端到端结果。

独立脚本：先备份，停用旧版本，在酒馆助手导入 v2.9.4 JSON，再刷新。

八卡内嵌版另行打包。其联系人、开场、时间与原始内容逐卡保留；已有内嵌手机时，不要同时开启独立版。

源码验证：`npm ci && npm run verify`。构建不依赖安装测试库：`node tools/release.js`。
