# v2.9.7 优化说明

> 目标：对小手机仓库做一轮全量检查，修复确有影响的问题，清理确认无引用的代码，让版本与文档不再需要手工同步。
> 本版本不新增功能，不改变存档格式；旧存档可直接升级。

## 一、检查方法

1. **整包静态分析**：对发布件 `dist/tsukiyo-phone-v2.9.6.js` 运行 ESLint（`no-undef`、`no-unused-vars`、`no-dupe-keys`、`no-unreachable` 等规则）。切片之间互相引用，逐文件分析会产生大量误报，因此以整包结果为准。
   - 结果：没有 `no-undef`、`no-dupe-keys`、`no-unreachable` 等错误；16 处 `no-unused-vars` 逐一在源码中核对。
   - 另有 66 处 `no-empty`（多为有意的 `catch {}`）与 8 处 `no-useless-escape`，属于风格问题，未改动。
2. **逐处核对**：每条“未使用”结论都用源码搜索确认。其中两处是误判，已恢复：
   - `arc/ui.js` 的 `arcPlanViewOriginal` 实际被中心页调用（名字容易误导，本版不改名）。
   - `center/ui.js` 的 `eng` 实际被使用。
3. **逻辑核对**：阅读召回（`picks`）、测活（`test-api`）等关键路径，并为修复补回归用例。

## 三、验证

- `npm test`：全部通过（冒烟 120 项、归属专项 26 项、契约 16 项、回归 29 项、安全 26 项）。
- `npm run test:ui`：全部通过（安全 UI 8 项、测活 UI 13 项、输入法与评审 UI）。
- 新增回归用例在旧包上会失败，在新包上通过（`tools/smoke_test.js` 的 `bodyTop` 用例）。
- ESLint 整包复查：`no-undef` 为 0。

## 四、升级注意

- 版本号改为 2.9.7。`dist/` 中旧的 2.9.6 产物已由 `release.js` 清理，新增 2.9.7 的独立版、卡内嵌版与酒馆助手导入版 JSON。
- 召回条数语义变化：`recallTop` 现在只统计摘要 / 账本 / 外部资料，`bodyTop` 只统计记忆正文。之前正文会占用 `recallTop` 名额，因此升级后注入的正文条数可能略多（上限为 `bodyTop`），总条数上限为两者之和。
- 旧手机导入（`legacy.js`）已不可用，但它在 2.9.2 之后就没有入口，实际用户不会受影响。
