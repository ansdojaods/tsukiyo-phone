## 新增场景重点

- 已生成档案从真实按钮正确打开，名字中的竖线与转义字符不丢失。
- 角色档案批删、跨页保留、取消、正文转义、上下文切换拒绝旧选择。
- 工坊批删持久排除、恢复、手机原文保留、第三方条目保留、远端变更拦截、失败重试。
- 只选人物时首次不写日记；长文无重复写出；人物取回后再次同步不反向覆盖。
- 手机与世界书同时修改时，工坊保留双方；不把灵魂远端文字虚报为五节回灌成功。
- 同一本工坊书的普通记忆按 UID 选择导入；不重复建书，不导入工坊条目。
- 记忆完整预览后批删，仅清理所选已关联远端记录。
- 生成或推演途中删除角色，迟到结果不能复活档案或注入旧内容。
- 手机记录合入修改事务草稿并真正保存。
- 未纳入当前同步的其他工坊条目不被自动删除。
- 记忆同步期间切聊天、本地输入变化会中止旧提交；选中范围保存到角色卡自动连接配置。

## 验证边界

- 逻辑测试用模拟宿主/世界书/API。
- jsdom 使用真实手机 UI 代码、按钮点击、复选框、表单提交、分页与仓库存储逻辑；模型和世界书读写仍为模拟接口。
- 没有真实酒馆扩展版本矩阵、真实供应商 API 或用户实际存档端到端结果。
- 没有证明手机存档与远端世界书是原子事务；远端先成功、本地后拒绝的部分成功场景仍需人工核对。
